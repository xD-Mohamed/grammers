# Visual assets

The architecture diagram and grammers mark are original ImageGen artwork,
created for this fork. The diagram intentionally shows only the main crate
dependencies. Link buttons are local SVG assets.

Generation brief: black backgrounds, restrained white and silver glass, only
crate names and connectors in the diagram; a simple transparent lowercase-g
symbol for the mark. No blue accents or decorative captions.

`github.svg` is the GitHub mark from
[Primer Octicons](https://github.com/primer/octicons), used under its
[MIT license](LICENSE-OCTICONS).
